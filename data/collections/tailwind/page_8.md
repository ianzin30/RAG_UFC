# Floats

| --- | --- |
| float-right | float: right; |
| float-left | float: left; |
| float-none | float: none; |

## [Anchor](https://v2.tailwindcss.com/docs/float\#responsive) Responsive

## [Anchor](https://v2.tailwindcss.com/docs/float\#customizing) Customizing

### [Anchor](https://v2.tailwindcss.com/docs/float\#variants) Variants

By default, only responsive variants are generated for float utilities.

You can control which variants are generated for the float utilities by modifying the`float` property in the `variants` section of your`tailwind.config.js` file.

For example, this config will also generatehover and focus variants:

```diff
  // tailwind.config.js
  module.exports = {
    variants: {
      extend: {
        // ...
+       float: ['hover', 'focus'],
      }
    }
  }
```

### [Anchor](https://v2.tailwindcss.com/docs/float\#disabling) Disabling

If you don't plan to use the float utilities in your project, you can disable them entirely by setting the`float`property to `false` in the`corePlugins` section of your config file:

```diff
  // tailwind.config.js
  module.exports = {
    corePlugins: {
      // ...
+     float: false,
    }
  }
```
